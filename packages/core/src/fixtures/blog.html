Why Plain Text Wins

Building a reading app is mostly an exercise in respecting the reader. Every pixel that is not the text competes with the text, and every network request that is not the article delays the article.

Plain text survives every migration. Files written decades ago still open today, while proprietary formats rot quietly in forgotten folders. That durability is a feature you only notice when everything else has failed you.
