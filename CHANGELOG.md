# Changelog

## 0.1.0

- Initial release: save-for-later reader with web app, browser extension, bookmarklet, share target, email-in and RSS capture.
- Highlights, tags, full-text search, import (Pocket, Omnivore, Instapaper, Readwise, bookmarks) and export (JSON, Markdown/Obsidian, EPUB).
- Send to Kindle via SMTP, optional AI summaries, Docker self-hosting.
