Later · open-source read-it-later

A self-hosted read-it-later app

Own your reading list. Later runs from a single Docker image with one volume for data, so there is no external database to set up.

Get Later on GitHubSelf-host guide

Hosted version coming soon. Self-host today.

Get started

  1. Run docker run -p 4800:4800 -v later-data:/data ghcr.io/ysta32/later.
  2. Open http://localhost:4800 in your browser.
  3. Import from Pocket, Omnivore, Instapaper, Readwise or browser bookmarks, or start saving with the bookmarklet, extension, or email-in.
  4. Optionally add a Claude key for summaries and ask-your-library. Without it, Later works the same minus AI.

Frequently asked questions

What do I need to self-host Later?

Docker. The command maps port 4800 and a named volume called later-data mounted at /data.

Where is my data stored?

In the later-data Docker volume you mount at /data.

Is a hosted version available?

Coming soon. Self-host today.

Is AI required?

No. AI summaries are optional and Later has a no-AI fallback.
